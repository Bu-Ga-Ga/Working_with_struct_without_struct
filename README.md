# Работа со структурами

Программа демонстрирует три различных подхода к хранению и обработке данных: 
1. Без использования структур
2. С использованием структур
3. С использованием объединения (union) для разных типов

## Структуры данных
### Три метода обработки
- Метод 1: Без структур (макросы)
  
    - Выделяется память как массив char[120]
    - Данные сохраняются в "сыром" виде
    - Доступ через макросы G, R, N

- Метод 2: Со структурами S1
  
    - Выделяется массив структур S1
    - Данные сохраняются в поля структуры
    - Доступ через st[i].group, st[i].rate и т.д.

- Метод 3: С union (структуры SS)
  
    - Выделяется массив структур SS
    - Данные сохраняются в соответствующую часть union
